# 분양 단지 대시보드 스타일 · 구조 가이드

챔피언스시티 1차 대시보드(직원 · 게스트 · 모바일 · SEO/GEO)를 만들면서 정한 구조, 화면 배치, 스타일, 작업 원칙을 정리했습니다.
다른 단지를 만들 때 이 문서를 기준으로 삼습니다.

---

## 1. 전체 구조

| 구분 | 주소 | 대상 | 파일 |
|---|---|---|---|
| 게스트 (공개용) | `/` | 고객 · 광고 유입 | `public/index.html` → `dashboard.dc.html` (guest-only) |
| 직원 | `/staff/` | 직원 · 관리자 (PIN 로그인) | `public/staff/index.html` → `dashboard.dc.html` (require-login) |
| 공유 서버 | `/api/*` | 직원 자료 공유 | `src/worker.js` + Cloudflare D1 |
| 기록 · 알림 | 구글 Apps Script | 시트 기록 · 텔레그램 | `gas/Code.gs` |

- 화면 본체는 **`dashboard.dc.html` 하나**입니다. 게스트와 직원은 같은 파일을 쓰고, 넘겨주는 값(guest-only / require-login)으로 화면이 갈립니다.
- 단지마다 **GitHub 저장소를 따로** 둡니다. 다른 단지 자료는 섞지 않습니다.
- 자료 저장
  - **화면 기준 자료**: Cloudflare D1. 모든 직원과 기기에서 같은 내용이 보입니다.
  - **백업 · 엑셀 확인용**: 구글시트. 시트를 직접 고쳐도 화면에는 자동 반영되지 않고, [구글시트에서 가져오기]로만 들어옵니다.
  - **기기 임시 저장**: 브라우저(localStorage). 서버에 올리기 전까지만 쓰입니다.

### 폴더 구조
```
저장소/
├─ wrangler.jsonc          D1 연결 (database_id)
├─ src/worker.js           /api/ping · pull · push · guest · hist
└─ public/
   ├─ index.html           게스트 (SEO 메타 · 구조화 데이터 · config.js)
   ├─ config.js            웹앱 URL 한 줄
   ├─ staff/index.html     직원 (noindex)
   ├─ dashboard.dc.html    화면 본체
   ├─ support.js           실행 파일 (수정 금지)
   ├─ sitemap.xml · rss.xml · robots.txt
   ├─ data/                options.json 등
   └─ assets/              로고 · 투시도 · 배치도 · 평면 · 유니트 · 모델하우스 · 공고 PDF
```

## 4. 상담카드 규칙

### 공통
- **잠금 원칙**: 아래 항목은 저장 후 잠깁니다. 바꾸려면 노란 사유 줄에 사유를 필수로 입력해야 하고, 기록이 남습니다.
  - 호실 (동호배치표에서 들어온 경우)
  - 성명 · 연락처 · 통신사
  - 담당자 확인
- **변동 기록**: 추가 상담 때는 바뀐 칸만 기록합니다. '이번 상담 변동사항 N건 ▼'를 펼치면 왼쪽에 이번 변동, 오른쪽에 지난 변동이 날짜별 한 줄로 나옵니다. 분양권부터 입주까지 같은 호실이면 이어서 보여 줍니다.
- **담당자**: 맨 오른쪽에 두고 직원 목록에서 고릅니다. 관리자나 권한자가 확인하면 잠깁니다.
- **통신사**: 기본값은 '선택하세요'. SK · 알뜰SK · KT · 알뜰KT · LGU · 알뜰LGU이고, 관리자가 추가할 수 있습니다.
- **연계호실**: 본인 호실 외 최대 3개. 서로 연동됩니다. 1개면 전체 폭, 2개면 2등분, 3개면 3등분으로 놓고, 연한 회색 독립 보드로 보여 줍니다.
- **동일 고객**: 휴대폰 번호가 같으면 동일 고객입니다. 오른쪽에 직전 상담 1건을 보여 주고, 나머지는 ▼로 접어 둡니다.
- **개인정보 가림**: 매수 · 신규 카드는 작성자 · 관리자 · 권한자만 전체를 봅니다. 나머지는 `홍**`, `010-****-****`로 보입니다.

### 진행표시 (중복 선택)
상담 · 급매 · 부재 · 광고중 · 광고중(타부동산)
- **광고중**: 광고매체를 고릅니다 (이실장 · 블로그 · 인스타 · 당근, 관리자가 추가 가능).
- **광고중(타부동산)**: 부동산명 드롭다운을 고르면 연락처가 자동으로 들어갑니다. 한 줄 6칸 구성입니다. 직접 입력이 11회 이상이면 목록 등록을 추천합니다.
- 둘 다 선택하면 보드를 좌우로 나란히, 하나만 선택하면 왼쪽 절반만 씁니다.

### 매물상태 (분양권)
| 상태 | 열리는 칸 |
|---|---|
| 매물 | 매물 등록일 (오늘 날짜 자동) + [광고등록] (광고중 자동 켜짐) |
| 가계약 | 입금일 · 예상 계약일 · 기타 (한 줄) |
| 계약 | 계약일 · 잔금일 · 기타 (한 줄) |
| 명의변경완료 | 칩 바로 아래에 신규 계약자 성명 · 연락처. 저장하면 계약자DB도 바뀌고 이전 기록이 남음 |

- 분양금액: 총액을 위에 보여 주고, 호실분양가 · 발코니 · 옵션은 ▼로 접어 둡니다.
- 납부현황: 계약금 1차부터 잔금, 옵션 10/10/80까지는 ▼로 접고, '납부완료(자납) · 매수자 실투자금'을 위에 보여 줍니다.
- 납부 형태: 자납 / 부분중도금대출 / 전체대출
- 추가조건: 양도세 부담 (칩 + 기타 협의 내용) · 매도희망시기 · 매도사유. 제목 옆에 고른 값을 요약 칩으로 보여 줍니다.

### 매물상태 (입주 · 소유자)
- 현재 계약형태: 미확인(기본) · 전세 · 월세 · 실거주 · 공실 · 신규(명변)
- 예상 계약종료일: 미확인 / 즉시입주 가능
- 계약주체(드롭다운): 본사 · 공동중개(상호) · 타부동산(상호) · 갱신연장
  - 갱신연장을 고르면 종료일이 +2년으로 자동 바뀌고 '갱신' 칩이 생깁니다. 갱신청구권 사용 여부와 인상금액 칸도 열립니다.
- 두 줄 5칸은 균등 폭으로 놓고, 기타 칸 뒤에 '갱신 후' 금액을 둡니다.
- 옵션사항: 분양권 단계의 옵션을 그대로 가져옵니다. 추가 옵션은 다른 색 칩에 ✕를 붙입니다. 같은 옵션을 10회 이상 직접 입력하면 선택 목록에 넣습니다.

### 매수 · 신규
- 유입경로 (중복 선택)
  - 방문: 방문일시 · 방문상담자
  - 유선: 네이버광고 · 당근 · 인스타 · 블로그 · 기타. 같은 내용을 5회 이상 직접 입력하면 자동 등록
  - 부동산: 상호 · 연락처 · 중개사
  - 지인: 관계
- 희망 동 · 층수대 · 타입, 총예산 · P예산, 확장 · 옵션 선호

## 5. 동호배치표

- **보기 전용**입니다. 입력은 모두 상담카드에서 합니다.
- 그룹 탭 예시: 101–103 / 104–106 / 107–109 / 110–112. 동 간 폭은 균일하게 맞춥니다.
- 셀 표시
  - 급매 셀에 '급' 배지
  - 필로티 · 빈 칸은 이미지와 같은 모양
  - 피난층 · 커뮤니티층 · 펜트 병합셀
- 호실내역
  - 제목 뒤에 빨간 '급매' 배지를 붙입니다.
  - 진행표시 줄 오른쪽 끝에는 부동산 상호만 미니칩으로 보여 줍니다.
  - 분양금액부터 전매 · 명의변경까지는 보기 전용이고, 납부현황 상세와 전매 · 명의변경은 ▼로 접어 둡니다.
  - [상담카드 →] 버튼으로 해당 호실 카드를 열면 호실이 잠긴 상태로 열립니다.
- 각 동 상단 타입 미니칩을 누르면 평면 팝업이 뜹니다.
- 호실이야기 (게스트 댓글): 접힌 상태가 기본입니다.
  - 관심등록한 사람만 글을 쓸 수 있습니다.
  - 전화번호는 `*`로 가립니다.
  - [중개요청] 칩이 있습니다.
  - 작성자는 자기 글만, 관리자는 모든 글을 지울 수 있고, 지운 글은 '삭제된 글입니다'로 남습니다.

## 6. 단지배치 · 평면

- **단지배치도**: 확대 · 이동이 됩니다. 동을 누르면 유니트 배치 팝업이 뜹니다.
  - 확대 버튼과 [← 뒤로] 버튼이 있습니다.
  - 바탕은 유니트 색과 일체감 있게 사각형으로 맞춥니다.
  - PH 박스는 잘리지 않게 오려서 옮깁니다.
- **유니트 → 평면 팝업**
  - 배치도에서 누르면 배치 방향대로 회전한 평면이, 하단 타입 칩에서 누르면 회전하지 않은 평면이 나옵니다.
  - 라인 · 유니트 · 타입이 항상 일치해야 합니다.
- **평면 팝업 (게스트)**
  - 상단: 같은 그룹 타입 칩 (예: 84A–84F), 다른 그룹은 대표 칩 (103 · 112 · 128 · PH)
  - 하단: [동호배치표] (최상층 기준) · [옵션계산기] · [관심등록]
- **모델하우스 사진**
  - PC: 평면 크기를 유지하고 오른쪽 열과 아래 줄에 사진을 놓습니다.
  - 휴대폰: 거실 썸네일 하나를 보여 주고, 가로로 넘기다가 누르면 확대됩니다.
- **흰 바탕 평면**: 원본 회색 바탕을 흰색으로 바꿔 모든 팝업을 같은 바탕으로 맞춥니다.

## 7. 게스트 기능

- **관심등록 / 방문예약**
  - 필수: 성명 · 연락처 · 생년월일(8자리 입력, `80.05.12`로 표시) · 개인정보 동의
  - 매도: 호실 + 매물상태 박스 (요구 P · 조정가능 P · 총분양금액 · 납부현황)
  - 매수: 관심호실 (자유기재) + 희망 조건. 선택사항은 ▼로 접어 둡니다.
  - 관심호실을 입력하면 상단에 `✓ 84B · 20층 배치표 →`가 나옵니다.
  - 등록이 끝나면 '작성되었습니다 · 상담문의 1800-XXXX' 팝업이 뜹니다.
- **개인정보 동의**: [필수] 수집 · 이용, [선택] 마케팅, [선택] 제3자 제공, [모두 동의]. [내용보기] 팝업이 있습니다.
- **저장 흐름**: 게스트가 등록하면 아래 네 곳에 들어갑니다. 직원 상담카드에서는 작성자 칸에 '게스트'라고 표시됩니다.
  - 구글시트
  - 텔레그램
  - 공유 서버 (`/api/guest`)
  - 직원 화면 🔔 알림
- **팝업 관리** (설정 → 공개 팝업관리 / 직원 팝업관리)
  - 기간 설정과 안내 설명을 넣을 수 있습니다.
  - 기간과 상관없이 끌 수 있는 스위치를 가운데에 둡니다.
  - '오늘 하루 보지 않기'와 PDF 다운로드가 있습니다.

## 8. 설정 · 권한

- **설정 · 거래모듈**은 관리자만 볼 수 있습니다.
- 화면 구성
  - 가로 약 1080px에 왼쪽 목차가 있습니다.
  - 모든 항목은 ▼로 접혀 있고, 하나를 펼치면 나머지는 닫힙니다.
- 담당자 · 권한
  - 직원을 추가할 때 이름 · 연락처 · 구글메일을 받습니다.
  - PIN 옆에 메일을 보여 줍니다.
  - 권한(관리자 · 직원 · 열람)은 ▼로 접어 둡니다.
- 목록 관리: 부동산 · 광고매체 · 통신사 · 유입매체. 각 목록에 [초기화] 칩이 있습니다.
- 메뉴 표시와 순서는 끌어서 바꾸고, [기본 순서로 되돌리기]가 있습니다.
- 공유
  - 처음 쓰는 기기는 사무실 코드(STAFF_KEY)를 한 번 입력합니다.
  - 상단에 '● 공유 저장됨 HH:MM'이 보이면 정상입니다.

  - 제목: 15–17px / 700–800
  - 본문: 13–14px
  - 보조: 11–12px
- 큰 숫자에는 `font-variant-numeric: tabular-nums`를 씁니다.
- 줄바꿈은 `text-wrap: pretty`를 쓰고, 칩 · 라벨은 `white-space: nowrap`으로 둡니다.

### 컴포넌트
- **칩 (pill)**
  - 모서리 9999px, 패딩 4–6 × 10–12px, 12–13px / 600
  - 선택됨: 검정 바탕에 흰 글자, 또는 타입 색 바탕
  - 선택 안 됨: 흰 바탕에 `#d2d2d7` 테두리
- **입력칸**: 높이 36–38px, 모서리 10px, 테두리 `#d2d2d7`, 14px. 잠긴 칸은 `#f5f5f7` 바탕에 🔒
- **토글**: 제목 옆에 `▼` / `▲`를 붙이고, 접힌 상태가 기본입니다. 선택된 값이 있으면 요약을 같이 보여 줍니다 (예: '3개 선택 ▼').
- **배지**: 급매 '급' (빨강, 9–10px / 800), NEW, 게스트
- **팝업**: 화면 가운데, 바탕은 `rgba(0,0,0,.5)`. 닫기 ✕는 상단 가운데 줄에 맞춥니다.
- **레이아웃**: 형제 요소는 `flex` / `grid`와 `gap`으로 정렬합니다. 2·3등분은 `repeat(n, minmax(0,1fr))`을 씁니다.
