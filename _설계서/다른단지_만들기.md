## 4. 단지 이름 · 주소 · 검색 문구 바꾸기 (S0 정리 끝, 2026-11-05)
코드에 직접 적힌 단지 이름은 없앴다. **site.json 만 고치고 도구 한 번** 돌리면 된다.
- `site` — `name` · `alias` · `short` · `address` · `slug`(영문, RSS 표시) · `brand`(붙여 쓴 이름 — 엑셀 · 백업 파일 이름, 텔레그램 알림) · `region` · `town`(광고 인사말) · `approvalNote`(매물 사용승인 기본값) · `parking`(매물 주차 기본값도 여기서) · `face0`(타입별 향 기본값)
- `office` — 사무소 (댓글 답글 이름 · 아래 정보 칸 · 광고 필수 표시)
- `seo` — 메인 제목 · 설명 · 키워드 · 공유 사진 · 검색용 단지 정보(`ld`) · 아래 정보 칸(`info`: 규모 · FAQ · 안내 링크) · 입지 페이지 설명(`locationDesc`) · 카카오 지도(`map`) · 해시태그(`tags` · `instaTags`, `{거래}` · `{타입}` 자리) · 당근 인사말 · AI 시험 문장. **`verify`(네이버 · 구글 확인 태그)는 비우고 새로 받는다**
- 사이트 주소: `wrangler.jsonc` SITE_URL 한 곳 (사이트맵 · RSS · 알림 링크 기본값 · 메인 대표 주소 · robots.txt 가 모두 여기서)
- 그다음 `node tools/apply_site.mjs` → index.html 머리말 · 아래 정보 칸, 직원 화면 제목, 위치 지도, robots.txt 를 다시 씀. `npm test` 가 파일과 site.json 이 다르면 알려 줌 (tests/site-files.test.js)

확인: `grep -rn -E "센테니얼|화정|hwajeong" src public --include=*.js --include=*.html --include=*.txt` (preview/ · assets/ 제외) → 주석 말고는 나오지 않아야 함
남은 것: `site.blocks`(1단지 · 2단지)처럼 **단지 구조**에 기댄 문구(광고 '단지 안내' · RSS 입주 시기)는 건물 여러 개 사이트(상무지구)에서 S1 때 같이 바꾼다.

## 5. Cloudflare 새로 만들기 (2026-11-04 배포 순서 그대로)
1. `npx.cmd wrangler login` (대표 계정)
2. `wrangler.jsonc` — `name` 새 이름 · D1 `database_name` 새 이름 · R2 `bucket_name` 새 이름
3. `npx.cmd wrangler d1 create <새DB> --location apac` → 받은 `database_id` 를 wrangler.jsonc 에 (`preview_database_id: "DB"` 는 그대로)
4. `npx.cmd wrangler r2 bucket create <새버킷>`
5. Turnstile 위젯 새로 (도메인 = 새 사이트 주소) → 사이트 키는 `public/config.js`, 비밀 키는 TURNSTILE_SECRET
6. 비밀값: STAFF_KEY(새 사무실 코드) · INDEXNOW_KEY(새로) · TG_TOKEN(**새 봇 권장** — 단지별 알림 분리) · GEMINI_API_KEY(같이 써도 됨) · ANTHROPIC_API_KEY(선택)
7. `npm test` → `npx.cmd wrangler deploy` → 주소 · /robots.txt · /sitemap.xml · 관심등록 시험 1건 확인
8. 대표 첫 로그인 `/staff` → 사무실 코드 → 대표 PIN → 직원 추가
